# SkyWars Minigame

## Overview
A simple SkyWars minigame for Minecraft Bedrock Edition, designed for Education Edition v26.32 on Windows. The game features a floating arena with 4 islands, a lobby, a start button or chat command, a 5-second countdown, randomized vanilla loot chests, free-for-all mode, elimination to lobby, winner announcement, and a podium.

## Features
- Floating arena with 4 islands and a lobby
- Start button or chat command
- 5-second countdown
- Randomized vanilla loot chests
- Free-for-all mode
- Elimination to lobby
- Winner announcement
- Podium

## Installation
1. Download the `.mcaddon` file.
2. Double-click the `.mcaddon` file to install it in Minecraft Education Edition.
3. Launch Minecraft Education Edition and enjoy the game!

## Usage
- Use the start button or type `/start` in the chat to begin the game.
- Eliminate other players to win the game.
- The winner will be announced and a podium will be displayed.

## Notes
- This minigame is designed for Minecraft Education Edition v26.32 on Windows.
- Teams, day/night controls, parkour, waterfall teleporting, special effects, and custom items are not included.
